Keypoints order = export index

Mirror pairs record which keypoints swap when an image is flipped horizontally — left flipper becomes right flipper. Training augments images by flipping them, so without these pairs the model learns left and right the wrong way round. Auto-pair L/R fills them in by matching left_… and right_… names; the ↔ badge shows what each point is paired with.

Shortcuts & controls

Mouse

Left drag
Draw a new marker (a single click for Point types)
Left drag a handle
Resize a box or ellipse, move a point, move a line end
Right drag
Pan the image — middle drag and Space + drag do the same
Wheel
Zoom towards the cursor
Ctrl + click
Delete the marker under the cursor
Shift while drawing
Constrain to a square or circle
Shift while rotating
Snap the angle to 15° steps

Handles appear on their own as soon as the cursor comes near a marker's edge — there is nothing to click first, and a marker can never be dragged around by its middle.

Lines

Drag
From one end to the other, in a single stroke
Click, then click
Place one end, then the other — easier when the two ends are far apart or you need to pan between them
Esc
Abandon a line waiting for its far end

Polygons

Click
Place the next vertex — good for corners
Drag
Trace a run of vertices along the cursor — good for curves. Mix freely with clicks.
Click the first vertex
Close the shape — Enter or a double-click do the same
Backspace
Take back the last vertex
Esc
Throw the whole polygon away
Click the + on an edge
Insert a vertex there and drag it straight out
Hold Alt
A bin follows the cursor and the vertex under it turns red — click to remove that one. A polygon keeps a minimum of three.

On a traced polygon only the vertices near the cursor show their handles, so the outline stays readable — all of them are still grabbable.

Poses

Drag a box
The type's skeleton drops in pre-posed, ready to adjust
Drag a keypoint
Move it — this also marks it as confirmed
Hover a keypoint, press O
Cycle it visible → occluded → absent, without stopping to select anything
Alt + click a keypoint
The same cycle, by mouse alone
Drag a box corner
Resize the box; the keypoints stay where they are

Keypoints you have not touched yet are drawn hollow and faded, so a template that was dropped in and never adjusted can't be mistaken for finished work. Define the skeleton itself in the marker type's Skeleton editor, which also imports and exports blueprints as JSON — hand the same file to everyone so a group's annotations stay compatible.

Properties

Every marker's geometry is in the sidebar, in absolute image pixels — exactly what the export writes.

The arrow on a marker type
Opens the list of markers placed with it, grouped by image
Click a listed marker
Jumps to its image, selects it, and centres the view
Selecting on the canvas
Opens that marker's row in the sidebar, so its fields are where you'd look
The number fields
Edit the geometry directly. Typing a width grows the shape rightwards — the top-left corner stays put.

A polygon has no size of its own, so editing its box moves or scales every vertex together. A pose lists each keypoint with its position and whether it is visible, occluded or absent.

Inspecting predictions

The third sidebar icon loads annotation CSVs and draws them on your images, matched by filename — predictions from a model, or an export from an earlier session. Each class becomes a marker type with a colour you can change, and removing a loaded file removes exactly the annotations it brought. Load the images first.

Exporting

Rows follow the layout YOLO uses for each task, in absolute image pixels: xc yc w h for boxes, four corners for a rotated box, a flat vertex list for polygons, and the box followed by every keypoint for poses. One file per encoding. Hover Export to take a single file or all of them.

Nothing is saved anywhere. Reloading or closing the tab discards every marker and marker type — export before you leave.
